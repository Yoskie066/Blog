# BlogSpace

BlogSpace is a simple and responsive blog application where users can write, create, and manage their own blog posts.

## Purpose

The purpose of BlogSpace is to provide users with a simple platform for creating and organizing blog posts. It also serves as a project for practicing the fundamentals of web development using HTML, CSS, and JavaScript.

## MVP Features

- **Home Page** – Introduces the application and provides navigation to other pages.
- **User Registration** – Allows users to create an account.
- **User Login** – Allows registered users to access their accounts.
- **Dashboard** – Displays the user's created blog posts.
- **Create Blog** – Allows users to write a blog post with a title and content.
- **View Blog Posts** – Allows users to read their published blog posts.
- **Responsive Design** – Provides a user-friendly interface across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
